Import & Export Data

Transfer your health data between devices or keep a backup

Chronic Health stores all data locally on your device — there's no account system and no live sync between devices. It backs your data up to your own iCloud Drive automatically, and the import/export feature lets you also move it manually using a backup file.

Do I need this?

In most cases, you don't. Starting with version 2.8.0, Chronic Health backs up all your data and photos to your own iCloud Drive automatically, after each day's survey. Install the app on a new iPhone or iPad signed into the same iCloud account, and it offers to restore your most recent backup when you first open it — no export needed. You can check when the last backup finished uploading in the app's Settings tab.

Automatic backups need iCloud Drive turned on for Chronic Health (Settings > [your name] > iCloud). Chronic Health's data is also included in Apple's standard iCloud Backup of your device, if you use it.

The import/export feature is useful when iCloud isn't an option — for example, if you don't use iCloud, if you skipped the restore offer, or if you want an extra copy you keep yourself.

What's included in the export?

An export captures everything in the app:

  • Configurations — all your symptoms, treatments (with side effects), illnesses (with symptom associations), and tags
  • Survey history — every daily survey you've completed, with all recorded values and notes
  • Photos — day photos and treatment reference images
  • Appointments — your providers and appointments, with their notes
  • Settings — your daily reminder time and whether reminders are enabled

How to export

  1. Go to the Settings tab
  2. Tap Export Data
  3. Choose where to save the file (iCloud Drive, Files, AirDrop, etc.)

The file is saved as a .zip file that you can store, share, or transfer however you like.

How to import

  1. Go to the Settings tab
  2. Tap Import Data
  3. Select a previously exported file
  4. Confirm when prompted

Important: Importing replaces all existing data in the app. Any data currently in the app will be overwritten. Export your current data first if you want to keep it.

Common use cases

Switching to a new phone

If you use iCloud, just install Chronic Health on the new phone and accept the restore offer. If you don't use iCloud (or want to be safe), export your data on the old device, transfer the file (via AirDrop, email, etc.), and import it on the new device.

Keeping a manual backup

The automatic iCloud Drive backup already covers this for most people. If you don't use iCloud, or want a copy outside it, periodically export your data and save the file somewhere safe. If anything happens to your device, you can restore your full health history.

Privacy note: The export file contains your health data in plain text. Treat it like any other sensitive personal information. Chronic Health never sends this file anywhere — you control where it goes. Automatic backups go only to your own iCloud Drive.

Troubleshooting

Import doesn't seem to work

Make sure you're selecting a file that was exported from Chronic Health. The file should be a .zip backup (or a .json file from an older version of the app). If the file is corrupted or from a different app, the import will show an error.

I accidentally imported and lost my data

If you had previously exported your data, you can re-import that earlier export file. If not, the overwritten data cannot be recovered — this is why we recommend keeping periodic backups.
